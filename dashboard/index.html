About this project

A small medallion batch ETL I built for capital-markets style trade data. Synthetic dirty CSVs land in bronze, get cleaned and deduped in silver, then join instrument reference data and business rules in gold.

The run also writes partitioned Parquet, executes SQL reconciliation across layers, and records a Spark shuffle / AQE tuning comparison with real timings. This page is the static metrics dashboard published from CI.

Full source and README

Architecture

  • Bronze Ingest trades CSV as strings, stamp ingest metadata, land raw Parquet.
  • Silver Normalize side codes, cast types, drop invalid rows, dedupe by trade_id.
  • Gold Broadcast-join instruments from Postgres (JDBC), apply lot/active rules, write date+venue partitions and aggregates.
  • Checks Spark SQL reconciliation across layers, plus baseline vs tuned shuffle timings into metrics.json.
CSV + Postgres → Bronze → Silver → Gold → Reconcile → metrics.json → Pages
